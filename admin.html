Gestion des offres

Cette page sert à ajouter, modifier ou supprimer les offres de mission du site. Rien ne change sur le site tant que les 3 étapes ne sont pas terminées.

  1. 1

    Préparer les offres

    Ajoutez, modifiez ou supprimez les offres ci-dessous. Les offres déjà en ligne sont chargées automatiquement.

  2. 2

    Télécharger le fichier

    Cliquez sur « Télécharger offres.json ». Le fichier arrive dans votre dossier Téléchargements. Ne changez pas son nom.

  3. 3

    Déposer le fichier

    Cliquez sur « Ouvrir la page de dépôt », glissez-y le fichier, puis cliquez sur le bouton vert « Commit changes ». Le site est à jour en une à deux minutes.

Charger les offres actuelles

Les offres en ligne n'ont pas pu être chargées. Choisissez le dernier fichier offres.json pour repartir des offres existantes.
